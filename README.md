# Nomi 家庭陪伴机器人 · 设计方案

- `index.html` 首页：三款外观、三种放法、演示视频
- `sim.html` 可交互、可拆解的 3D 模型（单文件，离线可开；`?style=nomi|cute|scifi` 选外观）
- `app.html` APP 配网流程、界面设计、家电互联方案
- `build.html` 样机制作指南：采购清单、尺寸图、接线表、步骤
- `cad/` 打印文件（STL，115% 比例：机身、夹座、隐藏 USB-C 滑门、地面充电座）和生成脚本 `make_shell.py`
- `firmware/` 样机程序（树莓派 Zero 2 W，Python；未经实物验证）
- `make.html` 制造流程、选材、三条充电路和底部接口定义、成本估算、AI 对话接入方案
- `demo.mp4` 97 秒演示视频

概念设计稿，成本与周期为估算值。
