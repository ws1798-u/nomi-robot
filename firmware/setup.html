对话模型

key 只存在这台机器里（settings.json），不会上传到别处，网页也不会再显示它。对话按你自己的 key 计费，不需要订阅。

语音（听写和说话）

DeepSeek 和 Claude 没有语音接口，要另配一个兼容 OpenAI 格式的语音服务（/audio/transcriptions 和 /audio/speech）。对话用 GPT 时可以都留空，直接借用上面的。

主动开口

允许它主动打招呼（回家迎接、早安、睡前提醒、到日子的事）

免打扰时段里看到你只做表情和亮灯，不出声。

迎接时转过来、往前迎两步（在桌上和充电时不动）

没人接话它就安静收住，不追问；连着被无视，它会自己隔得更久。也可以直接对它说“安静一会儿”。

家人和记忆

记忆按人分开存在这台机器里，可以随时改、删，也可以对它说“把那件事忘了”。“近期”的事过两周自动淡忘，有日期的过了那天几天后淡忘。
手机 IP：在路由器里给手机绑定固定 IP，并关掉手机上这个 Wi-Fi 的“私有地址 / 随机 MAC”。填了它就能知道谁回家了，没装认人模型时也能迎接。
